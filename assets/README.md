# Original assets

**Reserved structure only. No themes, fonts, icons or wallpapers are bundled.**

- `themes/`: future validated semantic theme data, not executable styling code.
- `wallpapers/sources/`: future original editable artwork.
- `wallpapers/exports/`: reproducible exports derived from reviewed sources.
- `icons/`: future original shell-specific icons, if needed.

No provenance manifest or asset license is invented by this scaffold. Add
`provenance.toml` when real assets and its schema exist, with author, source,
license, modifications, export recipe and hashes. Do not copy internet or
prototype artwork merely to populate these directories.

Theme names/palettes remain proposals. See the
[creative brief](../docs/blueprint/design.md),
[theme specification](../docs/blueprint/themes.md) and
[ownership policy](../docs/blueprint/ownership.md). `.gitkeep` files are not assets.
